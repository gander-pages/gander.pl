### Disable double lock screen

1.  Install package `dconf-editor`
2.  Toggle `/org/gnome/desktop/lockdown/disable-lock-screen`

Source: [How do I disable the Cinnamon 2 lock screen?](https://askubuntu.com/a/357038/678427)
