# Gander Site

Technical articles, code solutions and development guides, built with [Astro Starlight](https://starlight.astro.build/) and hosted on [Cloudflare Workers](https://developers.cloudflare.com/workers/static-assets/).

## Development

Requires [Node.js](https://nodejs.org/) v24 (see `.nvmrc`).

```bash
npm ci
npm run dev
```

| Command           | Description                        |
|-------------------|------------------------------------|
| `npm run dev`     | Start the dev server               |
| `npm run build`   | Build the site for production      |
| `npm run preview` | Serve the production build locally |
